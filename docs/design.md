# 界面、视觉与隐私措辞

布局按屏幕分、视觉是「水族箱里的计量仪」，以及应用里那些关于凭据的句子为什么这样写。回到 [README](../README.md)。

布局按**屏幕**决定信息怎么分：

| 屏幕 | 布局 |
| --- | --- |
| 手机（< 600dp，Android / iOS） | 底部四个 tab：概览 / 用量 / 花费 / 设置。区间筛选栏跟着数据切片走 |
| 平板与桌面（≥ 600dp，Web / Windows / macOS / Linux） | 一页看全；≥ 1000dp 自动分两栏——左栏拆解（Token 构成、模型明细、费用拆分、API Key 对比），右栏时间序列（每日趋势、构成对比、凭据说明） |

## 视觉语言

主题是**水族箱里的计量仪**：深水渐变从水面亮蓝落到深渊，所有面板都是水里的一块玻璃（真实模糊 + 边缘高光 + 顶部一道高光丝线），玻璃内部保持扁平——细分线、对齐的数字、等宽数位（tabular figures）配小一号单位。圆角按层级递减（18 / 15 / 11 / 4）。

吉祥物是**社区二创的「鲸鱼娘」**（DeepSeek 娘化的 Q 版女仆鲸鱼形象）：页头一枚头像，页面右下角一尊约 320px 的立绘压在玻璃之下。她同时是状态指示：**彩色 = 这些数字是你自己的；灰掉 = 页面在展示示例**。全页只有两处动效：入场淡入，和 dock 选中项的高亮。

**关于这个形象**：DeepSeek 官方**从未推出任何拟人形象**，鲸鱼娘全部来自社区二创。形象设定与出处见 [梗鲸 · DeepSeek娘角色百科](https://aigengtu.com/zh/whale-chan)；主流的女仆鲸鱼娘形象源自画师**上善无形** 2025-06 的 OC「溟月」（CC BY-NC-SA 4.0），女仆装版本由 **ZipZipPipe** 于 2026-04-25 设计（**原作者声明禁止商用**）。本项目是非商业开源工具，使用该形象仅作出处署名与非商业展示；**版权归原作者所有，若原作者有异议，会立即替换为自绘或已授权素材**。

资源文件：`assets/mascot.png`（全身）、`assets/mascot_head.png`（面部裁切，小尺寸用），以及 Android 启动图标（`mipmap-*/ic_launcher.png` 与 adaptive icon 的前景/背景分层）和 Web 图标（`web/favicon.png`、`web/icons/Icon-*.png`）。

颜色只承担两件事：`kAccent` 表示「这是你的真实数据」，`kWarn` 表示「这是示例」；每个展示示例数据的面板都带「示例」标签。

## 布局：一屏一件事

四个切片对两种输入方式给出两种导航，内容完全相同：

| 屏幕 | 导航 | 原因 |
| --- | --- | --- |
| 窄（< 600） | 底部浮动 dock | 拇指够得到 |
| 宽（≥ 600） | 左侧 `NavigationRail` | 鼠标有地方放标签，视线从左边起 |

切片是固定的四个：**概览**（余额与 Token 构成）、**用量**（趋势与模型明细）、**花费**（费用拆分与 API Key 对比）、**设置**（连接与凭据说明）。任何一页都不需要滚过另一页的内容——这正是把它们切开的原因。

宽屏每页内部仍可用两栏（`twoColumn`，≥ 1000）：用量页是趋势 + 模型明细并排，花费页是费用拆分 + API Key 对比并排。

## 玻璃透明度

设置里有「玻璃透明度」一项（滑杆 + 通透 / 标准 / 厚重 三个预设），带一块会跟着变的实时预览。它只改玻璃的厚度——填充白度、边缘亮度、模糊半径一起缩放——不改数据、不改配色，选择记在本机（`glass_strength`）。

## 关于凭据的措辞

应用内「设置」和连接面板都会显示这几条：

- **账号密码不经过本应用** —— 平台令牌在 DeepSeek 官方页面登录，本应用不接触你的账号密码
- **凭据放在哪里** —— 按平台给不同的答案，因为事实不同：浏览器里说「凭据保存在这个浏览器里（localStorage），换设备或清站点数据要重新连接」；装到机器上则说「凭据保存在这台设备上，断开或卸载即清除」
- **令牌怎么拿到** —— 同样按平台：浏览器里「网页版不用令牌」（同源策略 + CORS 双重拦截，令牌在网页里无法验证，只填 API Key 读余额）；原生客户端「可以在应用内直接登录」
- **只用于查询，不上传** —— API Key 和令牌只发给 DeepSeek 官方接口读取余额与用量；本应用没有服务器，不会发给任何第三方
- **保不保存由你决定** —— 默认只保存在本机；打开「不保存到本机」后凭据只留在内存里，退出即失效，并且会清除已经写入本机的凭据
- **输入框默认遮成圆点**，右侧眼睛按字段独立切换明文；**已经保存的凭据不会回填进输入框**，只显示 `已保存 ••••9f2c` 这样的后四位。留空点保存表示「继续用已存的那个」。保存成功后输入框立刻清空

这些句子由 `lib/services/credential_facts.dart` 按平台推导，不是两处手写。
